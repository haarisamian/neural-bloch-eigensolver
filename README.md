# Neural Bloch Eigensolver

Physics-informed neural networks for Bloch wavefunctions and band structures of 2D periodic potentials. Solves the Schrödinger equation for honeycomb lattices without labeled training data.

## Requirements
```
pip install -r requirements.txt
```

## Usage

See notebooks in `notebooks/` folder. Standalone training script and network intialization in pinn.py, additional analysis and results in notebooks.
